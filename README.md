# Jamie's Cafe Website

Landing page for Jamie's Cafe in Allen, Northern Samar. It presents the cafe's menu, contact information, and a browsable food-photo album.

## Features

- Responsive cafe page with menu categories and prices
- Holiday special photo
- Food album with previous/next controls and keyboard arrow-key navigation
- Cafe address, opening hours, phone number, email, and social links
- Local image assets; no build tools or package installation required
